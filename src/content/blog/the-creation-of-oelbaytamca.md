# Creating the site!

This is the first blogpost on my new site oelbaytam.ca! I used the [Astro Navfolio](https://github.com/dodolalorc/astro-navfolio) project as a template for it (I can code a site but I can't code a nice one ;-;). I am really happy with it and I am thinking of ways I can build off the template in ways that are useful and applicable to me. One idea I have is to display my pokemon binder on the web, thats an existing idea I had but never saw it through.

I never really considered making a blog, ever, but considering it came with the website it would be a good way to jot down things I think of from time to time. I'm not sure how consistent I will be but I created a repeating weekly reminder to create a blogpost every saturday. They will probably talk about my job hunt, things I learn, and projects I'm working on. Future readers will know looking back how truthful that is from the blog activity tracker on the [home](/) page.

Thats all I really have to say for this blog post, thanks for reading and hope you tune into whatever I may write in the future!
